# microbiomerecipes.com

Static site for **Microbiome Recipes**: original recipes built around fiber, fermented foods and plant variety, with one-click grocery carts. Hosted on Cloudflare.

## What's here

| Path | Page |
| --- | --- |
| `/index.html` | Landing page |
| `/learn/fiber/index.html` | Learn article: "Fiber: the strongest evidence" |
| `/recipes/overnight-oats-kefir-chia-raspberries/index.html` | Recipe page template (with schema.org Recipe markup) |
| `/assets/styles.css` | Shared styles and color tokens |
| `/assets/recipe.js` | Servings stepper on recipe pages |

These three pages come from the approved design. Other links point to the planned URLs in the site map (`/recipes/`, `/learn/`, `/fermenting/`, `/cookbook/`, legal pages and so on) and will 404 until those pages exist.

## Placeholders to fill

- Photos: every `figure.photo` is a labeled placeholder for the shot it needs.
- `[COUNT]`, `[PRICE]`, `[g]` (fiber per serving), `[DIETITIAN NAME, RD]`, `[DATE]`, storage times.
- Shop buttons: Instacart's official button (after demo approval and production keys) and the Chicory SDK (after publisher sign-up).

## Requirements

- **Accessibility:** WCAG 2.1 Level AA. Text contrast ≥ 4.5:1, keyboard access for every control, visible focus, alt text on every photo, labels on every form field, color never the only signal.
- **Recipe pages:** schema.org `Recipe` JSON-LD on every recipe (needed for Google and for Chicory). Add `image` in 16:9, 4:3 and 1:1 crops.
- **Instacart wording:** "Service fees apply.*", "Instacart may not be available in all zip codes"; no "partner", "Free Delivery" or health claims in Instacart messaging.
- **Health claims:** describe foods, not outcomes; cite a source for every gut-health note; "not medical advice" on every page.

## Deploy

Cloudflare Workers static assets, Worker `microbiome-website`, connected to this repo. Every push to `main` deploys to https://microbiomerecipes.com (no build step; `npx wrangler deploy` reads `wrangler.jsonc`). Files that must not be published go in `.assetsignore`.

`microbiomecookbook.com` and `microbiomedietcookbook.com` 301-redirect to `microbiomerecipes.com` (set in Cloudflare, not in this repo).

## Current layout (Nov 2026)

- `/` is a public **maintenance page**. It links nowhere.
- `/home-preview/` is the unlisted preview (noindex, not linked from any public page): the home mockup, the fiber article, recipe pages, `/home-preview/equipment/` and `/home-preview/supplies/`.
- Recipe, equipment and supplies pages are generated by `python3 tools/build_preview.py` (data lives in that script). `tools/` is not published.
- Shop buttons (Instacart, Chicory, Walmart, Amazon, Target) are disabled placeholders marked "Coming soon"; prices are `$XX.XX`.

## Google AdSense placeholders

- Every preview page has a commented spot in `<head>` for the AdSense loader script, plus labeled `aside.ad-slot` boxes (in-content 336×250 and leaderboard 728×90).
- To go live: paste the loader in `<head>` (generator: `head()` in `tools/build_preview.py`; hand-written: `home-preview/index.html`, `home-preview/learn/fiber/index.html`), replace each `.ad-box` with the matching `<ins class="adsbygoogle">` unit, and add `/ads.txt` with the publisher ID.
- The public maintenance page has no ad slots.

## Content editing (Decap CMS)

- Editor: https://microbiomerecipes.com/admin/ — sign in with a GitHub account that has write access to this repo.
- Content lives in `content/` as JSON: `recipes/`, `equipment/`, `supplies/`, `articles/`, and `settings/` (home featured recipe, cookbook page, lists and categories). Uploaded photos go to `assets/images/uploads/`.
- Every save is a commit to `main`. Cloudflare then runs the Build command `python3 tools/build_preview.py` (regenerates `home-preview/` from `content/`) and deploys.
- A recipe gets its own page once it has at least one Step. Equipment store buttons become live links once a link is entered.
- GitHub sign-in is handled by `worker/index.js` (`/api/auth`, `/api/callback`) using the Worker secrets `GITHUB_CLIENT_ID` and `GITHUB_CLIENT_SECRET` from a GitHub OAuth App whose callback URL is `https://microbiomerecipes.com/api/callback`.
- `content/`, `worker/` and `tools/` are not published (see `.assetsignore`).

## Instacart

- Recipe pages show one Instacart button. It stays "Coming soon" until **Site settings → Integrations → Instacart button live** is turned on in the editor.
- Each build writes the Instacart request for every recipe to `/data/instacart/<slug>.json` (quantities and units mapped to Instacart's accepted unit names; ingredients with "Include in shopping cart" off are skipped).
- Clicking the button calls `/api/instacart/<slug>` in `worker/index.js`, which creates the Instacart recipe page (365-day link), caches the link and redirects. Needs Worker secrets `INSTACART_API_KEY` and, for production, `INSTACART_ENV=production`.

## Ingredient substitutions

- `/home-preview/substitutions/` is generated from `content/substitutions/*.json` (editor: Substitutions). Each entry is either from a published source (currently Colorado State University Extension) or marked "Our suggestion — not yet tested".

- To bulk-update substitutions from Excel: `python3 tools/import_substitutions.py file.xlsx` (add `--dry-run` to check first). It replaces everything in `content/substitutions/`.
